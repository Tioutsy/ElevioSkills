# ELEVIO CLIENT ONBOARDING CHECKLIST & OPERATIONAL PLAYBOOK

## 1. Overview

This checklist serves as the operational guide for Account Managers and Customer Success Leads when onboarding a new enterprise client onto ELEVIO SKILLS.

---

## 2. Step-by-Step Client Onboarding Sequence

```
+-------------------------------------------------------------------------+
|                  ELEVIO ENTERPRISE ONBOARDING SEQUENCE                  |
|                                                                         |
|  [ 1. Contract Signed ] ---> [ 2. Tenant Provisioned in Admin Console ] |
|                                              |                          |
|  [ 4. Depts & Roles Configured ] <--- [ 3. Sector & Plan Assigned ]    |
|               |                                                         |
|  [ 5. Strategic Priorities Selected ] ---> [ 6. Mandatory Training Set ]|
|                                              |                          |
|  [ 8. Path Review & Verification ] <--- [ 7. Employee CSV Dispatched ]  |
|               |                                                         |
|  [ 9. Company Launch Announced ] ---> [ 10. Day-7 & Day-30 Follow-Up ]  |
+-------------------------------------------------------------------------+
```

### Phase 1: Commercial & Account Setup (Day 0)
- [ ] **1.1 Enterprise Agreement Executed:** Contract signed, seats agreed, billing terms confirmed.
- [ ] **1.2 Tenant Provisioned:** Platform Admin creates company account in Admin Console and assigns appropriate plan tier.
- [ ] **1.3 Company Admin Invited:** Welcome email dispatched to designated client HR/Sustainability lead.

### Phase 2: Configuration & Personalization (Days 1–2)
- [ ] **2.1 Primary Sector Confirmed:** E.g. `SEC_HOSPITALITY`, `SEC_MANUFACTURING`, `SEC_FINANCE`.
- [ ] **2.2 Department Matrix Configured:** Client departments mapped (e.g. Housekeeping, F&B, Facilities, Finance).
- [ ] **2.3 Strategic Priorities Selected:** Select up to 4 corporate sustainability focus areas (e.g. Energy, Water, Waste).
- [ ] **2.4 Mandatory Compliance Selected:** Designate any required universal compliance modules (e.g. `ELH-32` Ethics).

### Phase 3: Employee Ingestion & Launch (Days 3–5)
- [ ] **3.1 CSV Preparation:** Clean client roster (First Name, Last Name, Work Email, Department, Job Title).
- [ ] **3.2 Ingestion & Validation:** Upload CSV via Company Admin console; verify zero duplicates or missing metadata.
- [ ] **3.3 Sample Path Review:** Preview 3 generated paths (Frontline, Manager, Executive) to confirm role accuracy.
- [ ] **3.4 Launch Dispatched:** Send invitation emails to all enrolled employees.

### Phase 4: Customer Success Cadence (Days 7–30)
- [ ] **4.1 Day 7 Health Check:** Review initial activation rate; resend invites to unactivated staff.
- [ ] **4.2 Day 14 Engagement Review:** Monitor course starts and early completion trends.
- [ ] **4.3 Day 30 Business Review:** Export progress compliance report and present workforce completion summary to leadership.
