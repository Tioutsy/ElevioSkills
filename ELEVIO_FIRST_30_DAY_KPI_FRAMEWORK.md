# ELEVIO SKILLS FIRST 30-DAY OPERATIONAL KPI FRAMEWORK

## 1. Executive Summary

This framework establishes the operational metrics and review cadence for measuring the success of initial enterprise client cohorts during their first 30 days of active deployment.

---

## 2. Core 30-Day Operational KPI Metrics

| Metric Name | Calculation Method | Target Milestone (Cohort Benchmark) | Operational Action if Below Target |
| :--- | :--- | :---: | :--- |
| **Company Activation Rate** | `(Configured Tenants / Created Tenants) * 100` | **$\ge 90\%$** | CSM reaches out to assist admin with department setup. |
| **Learner Activation Rate** | `(Activated Learners / Invited Learners) * 100` | **$\ge 75\%$ within 7 Days** | Trigger automated reminder email to unactivated staff. |
| **Profile Completeness Index**| `(Complete Profiles / Total Learners) * 100` | **$\ge 85\%$** | Admin console prompts HR to complete missing roles. |
| **First Course Start Rate** | `(Started Course / Activated Learners) * 100` | **$\ge 70\%$ within 14 Days**| Send "Start Your Next Best Course" nudge notification. |
| **First Course Completion Rate**| `(Completed Course / Started Course) * 100` | **$\ge 80\%$** | Review course duration and scenario difficulty. |
| **Assessment Pass Rate** | `(Passed Quizzes / Attempted Quizzes) * 100` | **$80\%\text{--}90\%$** | Ensure passing standard is rigorous yet achievable. |
| **Support Incident Rate** | `Support Tickets / Active Learners` | **$< 2.0\%$** | Update Admin Quick-Start Guide and FAQ documentation. |

---

## 3. First 30-Day Review Cadence

- **Day 1 Check:** Verify database health, invitation dispatch, and first login events.
- **Day 3 Check:** Review email delivery rates, initial activation trends, and profile completeness.
- **Day 7 Check:** Measure early course starts, quiz pass rates, and support ticket categories.
- **Day 14 Check:** Review mid-cohort completion progress and departmental leaderboards.
- **Day 30 Review:** Comprehensive Post-Launch Operational Review to establish empirical baselines and prioritize Release 1.1 backlog enhancements.
